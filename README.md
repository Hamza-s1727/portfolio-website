# My portfolio Website

This is a website that holds information about myself, projects and other information.

# Live Demo
You can find it at www.hsheikh.com. Bootstrapped with Create React App and Deployed via Microsoft Azure

# Features
- A responsive design, the website is responsive and adapts to screen sizes for both mobile and desktop
- Animations using the framer motion library
- Contact Form: A contact page powered by Web3forms

# Setup Instructions

If you want to run this project locally, make sure you have node.js and npm installed, Install all dependencies with ```npm install```, then run ```npm start```

# Form Configuraton

If you want the contact form to go to your own email, Set up a web3forms account to get an API key. 
Note this API key is only used to submit form data to an email, so there is no need for an `.env` file (unless you are looking to hide your email for some reason).
